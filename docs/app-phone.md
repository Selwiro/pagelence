## 三、阅读方式与分页

阅读方式由 `Preferences.readerLayout` 控制，默认 `PAGED`（翻页）。旧状态没有
`readerLayoutChosen` 时视为旧默认，自动落到翻页；用户在设置页明确选过之后才保留
`SCROLL`。

**翻页模式**（`PAGED`）

- `SentencePaginator`（`:core`）按句级高度装页，句子不拆，段落可跨页；不再把长句切成
  40 词片段，正文按原书的自然段连续渲染。
- `ReaderScreen` 用 `TextMeasurer` 按当前宽度、字号、导读模式测量句子，留出 42dp 给
  底部页码胶囊，再装页；同一页内的多句合成一个 `Text`，不在句与句之间另起文本块。
- 分页结果按「书 + 单元 + 正文宽/页高 + 字号 + 字体 + 行距 + 页边距 + 是否显示全部句译 +
  语言 + 密度 + 正文指纹」缓存在 `:presentation` 的 `PaginationCache` 里（最近 8 个单元）；翻页、答题、加标记引起的状态
  重建不再深比较整段正文，回到读过的单元直接复用。书签/划线/笔记画在文字之后、不进指纹，
  所以加标记不会触发重新分页。
- 左右滑动翻页，并保留与页边距同宽（窄 14dp / 标准 22dp / 宽 32dp，最多 22dp）的边缘点按，
  点按区只落在正文留白内，不会盖住行尾的字；不再有底部控制栏。
- 句末「译 / 析」图标视觉仍是 14dp，点按判定向外扩 14dp；上下滑动模式与翻页共用 760dp 正文宽度。
- 在单元首尾可以跨单元滑动：语法页继续向前滑进入下一单元的导读页；导读页向后滑回到
  上一单元的语法页。首单元没有上一段、末单元没有下一段时不出现越界页；过渡页不写入续读点。
- 正文页底部只有「i / n」胶囊；最后一页胶囊显示「进入测验」，点按进入测验。
- 阅读页的菜单是按需覆盖层（T167）：点正文空白处出现底部一行「目录 / 书签与笔记 / 设置 / 生词卡」，
  再点空白处、点返回或完成任一动作即收起；覆盖层不改变正文排版，弹出与收起都不会重新分页。
  点单词、句末图标、按钮或左右翻页热区时由这些元素先消费，不会误弹菜单；滚动模式与可滚动的
  长页把点击层放在滚动内容内部，因此页内空白处同样可呼出。顶栏不再有目录按钮，下拉菜单已取消，
  书内搜索改为顶栏右上角的搜索图标。
- 底部菜单「设置」展开内联「阅读设置」面板。字体/边距类用自绘细轨滑杆（3dp 轨、圆点旋钮、
  30dp 高），字号六档（15/17/19/22/25/28sp）、页边距三档、行距三档，滑到档位才写入偏好；
  阅读字体与阅读方式经常在阅读中调整，标签与 2 个 chip 同一行；词义语言与导读模式改得少，
  收成一行「当前值 ›」，点开弹出选项列表（ChoiceSheet）。面板高度上限为可用高度的 88%，超出
  可滚动。改字号/页边距/行距/字体时翻页模式会按比例重新分页并保持当前阅读位置（记住的是
  正文页比例而不是页码），上下滚动模式则保持滚动偏移。
- 排版偏好（T158，字号于 T167 扩为六档）：正文字体（无衬线/衬线）、字号六档（15/17/19/22/25/28sp）、行距三档（行高 1.45/1.62/1.85）、
  页边距三档（14/22/32dp）都写进 `preferences`；正文渲染与分页测量共用同一个
  `readingTextStyle`，改任一项都会让分页缓存按新 key 重算，翻页与上下滑动模式一致。
- 整句翻译（T159）：顶栏「文A」开关打开后，所有有 `zh` 的句子在原文下另起一行显示中文，
  句末逐句「译」图标隐藏；开关状态写 `preferences.showAllTranslations`，重启后保留。
  中文是显示内容，点按或长按不会触发查词/句子动作。
- 句译入口是句末 14dp「文A」图标，像脚注标记一样内联在段落文字中；有 `analysis` 的句子末尾
  另有一个 14dp 句法树图标（不再是「解析」小字），与句译图标同高、完整显示，点开底部卡片，
  顺序为主干 → 成分 → 语序 → 提示；卡片可滚动，「收起」或下滑关闭；英文界面没有 `en` 时只
  显示主干、role 标签与成分原文，不回退中文。
- 点译图标后在该句下方
  展开中文，再点一次收起。展开只影响当前句所在段落的后续排版，不显示弹窗。

**上下滑动模式**（`SCROLL`）

- 正文是一整列可连续滚动的段落；滚到底显示「进入测验」按钮。
- 顶栏下的四个进度分块可点击：导读、正文、第一道测验、语法分别跳转；正文回到当前/上次正文页。滚动比例仍用于填充正文块。
- 两种模式共用顶栏、进度条、点词、句译和测验/语法页面。

**续读与返回**

- 每个单元在 `BookProgress.reader` 保存 `ReaderPosition`：环节（导读/正文/测验/语法）、
  正文页、滚动比例、测验已选答案、是否已提交、是否到过语法。
- 点顶栏返回或系统返回都保存当前 `ReaderUiState` 的续读点；再次打开书回到离开的页或环节，
  测验已选答案保留。
- 点语法页的「继续下一段」先进入下一单元的导读页；点「开始阅读」再进正文。下一单元没有导读时直接进正文。
- 在语法页返回，本单元计入已读并记一次完成；在正文/测验中途返回只记
  位置，不计已读。跨单元滑动前会先保存当前单元的续读点。
- 不再提供「今天读到这里」；返回即视为本次阅读到这里。
- 阅读页不显示底部页码/前后页控制栏；翻页模式用正文页底部胶囊，滚动模式用正文末尾按钮。

## 三·五、书内搜索与查词历史（2026-11-22，T160 / T161）

### 书内搜索

- 入口：阅读页顶栏右上角的搜索按钮，搜索页压在阅读页之上，返回回到原来的页与单元。
- 输入即搜：英文原句大小写不敏感，已有句译同样可命中；一条句子只出一条结果（原文优先）。
- 结果按章节/单元分组，显示高亮命中片段与另一种语言的上下文；最多 150 条，超出提示截断。
- 点结果：翻页模式落到包含该句的页；上下滑动模式把所在段落滚到顶部。搜索页保留上次查询，
  再次打开同一本书时直接回到上次结果。
- 规则在 `:core` 的 `BookSearch`（纯 JVM，含片段截取、排序、上限与截断单测），标题映射在
  `:presentation` 的 `SearchPresenter`；空查询、无结果各有空态。

### 查词历史

- 每次点词查义后写一条 `lookupHistory`：词面、原形、简短释义、音标、书/单元/段落/句号、
  词在句中的范围与时间；同一本书同一原形只留最新一条，最多 200 条。
- 复习 →「查词」按时间倒序显示；书与单元标题从 `outline.json` 取，不解析整本书；书已移除
  时标「书籍已移除」且不可点。
- 点一条：打开对应单元并定位到该句，随后重新打开词义面板。
- 「清空历史」二次确认；生词卡与进度不受影响。
- 历史随 `state.json` 导出/导入与同步；合并按 `id` 取 `lookedUpAt` 较晚者。

## 四、阅读序列与导读

页面序列为 `导读 → 正文（翻页页 / 连续滚动）→ 测验 1..3 → 语法`。翻页模式还在导读前、
语法后各加一个过渡页，只用于跨单元滑动：落定后打开「上一段 · 语法」或「下一段 · 导读」，
过渡页本身不保存续读点。

- 导读页只放章节/单元标题与导读文本（中/英；沉浸跳过）；长导读自身可滚动。
- 导读页有两个按钮：「开始阅读」进入正文；「预习」打开本单元的高一级词汇。
- 预习按本书 CEFR 等级 +1 起筛选（A2 书取 B1 及以上，B1 书取 B2 及以上）；先只显示单词、
  音标和等级，询问「认识 / 不认识」。认识只展开解释；不认识展开解释并加入生词卡。
  每个词点「下一个」推进，全部学完后显示「预习完成」与「开始阅读」。
- 导读不再从顶栏回看；是否再弹由 `Preferences.seenGuideUnits` 决定。
- 测验一页一题：选择后立即判对错、显示反馈与「看原句」，再「下一题」；最后一题提交后
  直接进入本单元语法，没有语法就进入下一单元导读。
- 没有总结页，也没有「本轮回顾」。语法页先显示语法点标题与一句话介绍，再放本书原句，
  随后是结构/作用/易错/本句等语法解析，库的完整说明点「展开看这个语法点」才显示；

## 六·九、读完页与重读（2026-11-22，T139）

## 六·十一、每日目标与阅读时长（2026-11-22，T162）

- **今天的时长**：只在阅读页处于前台时累计。进入阅读页、或从后台回到仍在阅读页时开始

- **数据**：`dailyActivity[YYYY-MM-DD].readingSeconds`（可选字段，旧文档为 0），单日上限
  12 小时；合并与单元数同口径——同一天取 max。计时规则在 `:core`（`ReadingStreakRules`
  的达标/连续与 `DailyActivityRules.recordReadingSeconds`），不新增权限、不跑后台服务。
- **每日目标**：设置 → 阅读 →「每日目标」，5 / 10 / 15 / 20 / 30 分钟，默认 10；写
  `preferences.dailyGoalMinutes`，越界值读回落 10。
- **今日卡**：我的页统计上方。「今日」+ 连续 chip；大字 `已读 X / 目标 Y 分钟`；进度条按
  `todaySeconds / 目标秒数` 夹在 0–1；下面一行 `今日已达标` 或 `还差 N 分钟达标`，再拼
  「今日读完 N 个单元」与「最长 M 天」。
- **连续天数**：当天达标（`readingSeconds ≥ 目标 × 60`）才算。今天还没读够时按昨天往前
  数，所以白天打开不会看到连续突然归零；断一天只把当前连续归零、最长连续保留，chip 显示
  「今天重新开始」，不出现「断签」「失败」。旧数据里只有单元数、没有秒数的日子按达标算，
  升级不会清零已有连续。
- **不做**：推送提醒（F-12 明确不做，见 `management/project-design.md`）、后台计时、
  周目标、惩罚式断签、成就或锁屏挂件。

```

    ├── ui-m3 (Android library, Compose Material 3)
    │     页面、组件、主题、UI 模型、双语文案；只接数据与回调
    ├── presentation (纯 JVM)
    │    UI 模型、双语 Strings、ReaderSession（续读点/读完判定）、
    │    ReaderFlow（页序）、LibraryPresenter（书架/我的）、ReaderPresenter（单元状态）、
    │    WordPanelPresenter（点词→词条面板）、StorePresenter（书城）、
    │    AssessmentPresenter（测评）、BookDetailPresenter（书籍详情）、
    │    GrammarPresenter（语法库）、DictionaryPresenter（完整词表）、
    │    SyncPresenter（同步状态）、PreviewPresenter（预习词）、
    │    SettingsPresenter / FinishedPresenter / WordCardPresenter
    ├── data (纯 JVM)
    │     state.json 读写；进度、卡片、偏好、等级与日活仓库
```

- `ui-m3` 不依赖 `data`，不写存储规则；分页高度测量在 UI，分组规则在 `:core`。

- `SpeechController` 在 `app-phone`，用系统 TTS；`ui-m3` 只接 `onSpeakWord/onSpeakSentence`。
- 随包内容经 `ContentSource` 读取：APK 用 `AssetContentSource`（`AssetManager` 适配），下载书用 `FileContentSource`；不再复制到 `filesDir`。

### `:presentation` 的边界（M5 复用）

`:presentation` 只依赖 `:core` / `:sync`，不含 `android.*`。它承担“把数据变成界面模型”的规则：
UI 模型与双语文案、阅读会话（续读点/读完判定）、页序、单元阅读状态、词条面板、书架/我的统计、
书城、书籍详情、测评、语法库、完整词表、同步状态、预习词、设置/完成页/生词卡列表。

壳层（`app-phone` 或未来的墨水屏壳）保留：导航栈与 `Screen`、协程与线程切换、`AppGraph` 装配、
TTS/文件选择器/网络/Keystore 等平台服务，以及把 presenter 结果写进状态流。

给 M5 的最小接入：装配自己的 `AppGraph` 等价物（内容源 + 四个仓库 + 平台服务），用
`ReaderPresenter` 产出 `ReaderUiState`、`ReaderFlow` 决定页序、`ReaderSession` 保存位置；
其余页面用对应 presenter 取 `…UiState`，不需要复制文案或映射代码。

## 八、存储

用户数据只有一份 `state.json`（`filesDir/state.json`），格式即 `docs/progress-format.md` 的 `ReadingState`
v2：进度、已读单元、生词卡（含墓碑）、句子标注 `annotations`（书签/划线/笔记，含墓碑）、
偏好（主题/字号/`speechRate`/`seenGuideUnits`/`levelOnboardingDone`）、等级、日活、
`deviceId`、`updatedAt`。写入用临时文件 + 原子改名；
成功读取后保留一份 `state.json.bak`，主文件损坏时从备份恢复并把坏文件存为
`state.json.corrupt`，只有主备都坏才回退为空状态并在启动时提示。v1 升级时自动迁移，
更高版本只读已知字段、不自动改写。

阅读页的续读点在翻页、切换环节、滚动停止和答题时写入：连续变化按 300ms 防抖合并，
写入串行化，旧快照不会覆盖新位置；`ON_STOP` 与 `onCleared` 强制 flush。进程被杀后从
同一页、同一环节和同一组测验选项恢复，段落锚点与续读点在同一次写入里更新。

内容包不落在用户目录：随包内容直接从 APK `assets/` 读取，只有下载/导入的书进入
`filesDir/downloaded/`，完整词表在 `filesDir/dictionaries/`，都可用设置或书城删除。

**与设计稿的差异**：android-design.md 第九节计划 Room。M2 先实现为 `ReadingStateStore`
（纯 JVM、可单测），因为同步/导出本来就是这份 JSON；仓库接口已在 `:core` 固定。
