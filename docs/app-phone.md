### 默认封面

书架与书城不再用单字色块，统一显示排版封面：深色底、英文书名、作者、`PAGELENCE` 字标、
一条强调色横线和按书固定的几何装饰。同一本书用 book id 稳定取色，五本内置书各指定一套配色
（杜立德苔绿、爱丽丝雾紫、四签名石板、盖茨比墨蓝、红字赭褐），下载书按 id 散列。封面上的
字号用 dp 换算成 sp，不随系统字体缩放撑破版面；书名最多四行、作者最多两行，短书名会缩到
一行放下。`BookCover` 预留可选封面图参数，书籍自带封面图时可直接替换；当前两本内置书没有
封面素材，全部走默认排版。

## 三、阅读方式与分页

阅读方式由 `Preferences.readerLayout` 控制，默认 `PAGED`（翻页）。旧状态没有
`readerLayoutChosen` 时视为旧默认，自动落到翻页；用户在设置页明确选过之后才保留
`SCROLL`。

**翻页模式**（`PAGED`）

- `SentencePaginator`（`:core`）按句级高度装页，句子不拆，段落可跨页；不再把长句切成
  40 词片段，正文按原书的自然段连续渲染。
- `ReaderScreen` 用 `TextMeasurer` 按当前宽度、字号、导读模式测量句子，留出 42dp 给
  底部页码胶囊，再装页；同一页内的多句合成一个 `Text`，不在句与句之间另起文本块。
- 左右滑动翻页，保留左右各 22dp 的边缘点按（等于正文左右留白，不会盖住行尾的字）；不再有底部控制栏。
- 句末「译 / 析」图标视觉仍是 14dp，点按判定向外扩 14dp；上下滑动模式与翻页共用 760dp 正文宽度。
- 在单元首尾可以跨单元滑动：语法页继续向前滑进入下一单元的导读页；导读页向后滑回到
  上一单元的语法页。首单元没有上一段、末单元没有下一段时不出现越界页；过渡页不写入续读点。
- 正文页底部只有「i / n」胶囊；最后一页胶囊显示「进入测验」，点按进入测验。
- 句译入口是句末 14dp「文A」图标，像脚注标记一样内联在段落文字中；有 `analysis` 的句子末尾
  另有一个 14dp 句法树图标（不再是「解析」小字），与句译图标同高、完整显示，点开底部卡片，
  顺序为主干 → 成分 → 语序 → 提示；卡片可滚动，「收起」或下滑关闭；英文界面没有 `en` 时只
  显示主干、role 标签与成分原文，不回退中文。
- 点译图标后在该句下方
  展开中文，再点一次收起。展开只影响当前句所在段落的后续排版，不显示弹窗。

**上下滑动模式**（`SCROLL`）

- 正文是一整列可连续滚动的段落；滚到底显示「进入测验」按钮。
- 顶栏下的四个进度分块可点击：导读、正文、第一道测验、语法分别跳转；正文回到当前/上次正文页。滚动比例仍用于填充正文块。
- 两种模式共用顶栏、进度条、点词、句译和测验/语法页面。

**续读与返回**

- 每个单元在 `BookProgress.reader` 保存 `ReaderPosition`：环节（导读/正文/测验/语法）、
  正文页、滚动比例、测验已选答案、是否已提交、是否到过语法。
- 点顶栏返回或系统返回都保存当前 `ReaderUiState` 的续读点；再次打开书回到离开的页或环节，
  测验已选答案保留。
- 点语法页的「继续下一段」先进入下一单元的导读页；点「开始阅读」再进正文。下一单元没有导读时直接进正文。
- 在语法页返回，本单元计入已读并记一次完成；在正文/测验中途返回只记
  位置，不计已读。跨单元滑动前会先保存当前单元的续读点。
- 不再提供「今天读到这里」；返回即视为本次阅读到这里。
- 阅读页不显示底部页码/前后页控制栏；翻页模式用正文页底部胶囊，滚动模式用正文末尾按钮。

## 四、阅读序列与导读

页面序列为 `导读 → 正文（翻页页 / 连续滚动）→ 测验 1..3 → 语法`。翻页模式还在导读前、
语法后各加一个过渡页，只用于跨单元滑动：落定后打开「上一段 · 语法」或「下一段 · 导读」，
过渡页本身不保存续读点。

- 导读页只放章节/单元标题与导读文本（中/英；沉浸跳过）；长导读自身可滚动。
- 导读页有两个按钮：「开始阅读」进入正文；「预习」打开本单元的高一级词汇。
- 预习按本书 CEFR 等级 +1 起筛选（A2 书取 B1 及以上，B1 书取 B2 及以上）；先只显示单词、
  音标和等级，询问「认识 / 不认识」。认识只展开解释；不认识展开解释并加入生词卡。
  每个词点「下一个」推进，全部学完后显示「预习完成」与「开始阅读」。
- 导读不再从顶栏回看；是否再弹由 `Preferences.seenGuideUnits` 决定。
- 测验一页一题：选择后立即判对错、显示反馈与「看原句」，再「下一题」；最后一题提交后
  直接进入本单元语法，没有语法就进入下一单元导读。
- 没有总结页，也没有「本轮回顾」。语法页先显示语法点标题与一句话介绍，再放本书原句，
  随后是结构/作用/易错/本句等语法解析，库的完整说明点「展开看这个语法点」才显示；
  不显示语法库其他例句。滚到底部显示「继续下一段 / 读完全书」。
- 顶栏下的进度条按导读 / 正文 / 测验 / 语法分成四个可点击按钮；正文按页数或滚动比例、测验按已答数填充。

## 六·五、我的页与测评

- 「我的」由三块组成：水平卡（等级、来源 chip、一句说明、修改等级/语言水平测评）、
  三项统计（读完本数、跨书已读单元、阅读天数）、学习热力图（真实网格）。
  2026-11-19 反馈移除了「最近阅读」与「按书进度」；续读仍在书架与阅读页完成。
- 测评入口在水平卡；两种模式一页一题，作答不即时判对错，避免边做边猜；最后一题提交后
  进入结果页。
- 结果页给总分、参考区间或单级、分项条形图，以及「接受新等级 / 保留原级」：
  - 接受：先弹与自评相同的等级提示；确认后写 `selfLevel`、`levelSource`（quick/full）、
    `levelScore`、`levelUpdatedAt`，并按读者的选择写界面语言、词义语言与导读模式；
  - 保留：只写 `levelScore` 与 `levelUpdatedAt`，等级与来源不变。
- 不设冷却：结果页确认后即可再次进入测评；自评/手动改等级仍会清空 `levelScore`。
- 作答页每题都有「跳过此题」：不确定时不必乱猜，跳过后计为未答对并直接进入下一题；
  已选答案后跳过会清除该题选择。
- 答题中点返回（顶栏或系统返回）先确认，避免丢掉已答内容；确认退出会保存续读点与已选答案，下次回到测验。
- 题库在 `content/assessment/bank.json`；`AssessmentRules` 负责抽题与评级，
  UI 只渲染 `AssessmentUiState`。

### 等级提示（2026-11-21）

等级只给推荐值，改设置前先让读者确认。自评「开始阅读」、我的「修改等级」、测评「接受新等级」
三条路径共用同一个底部弹窗：

- 标题带等级名与来源（自评 / 快速测试 / 高级测试），正文说明可以接受、保持或自己挑；
- 只列真正会变的项，格式「当前 → 推荐」：界面语言、词义语言、导读模式；三项都符合推荐时
  不弹窗，直接应用；
- 三个动作：**接受推荐**（写三项推荐）、**保持原来的设定**（只写等级，不动偏好）、
  **现在自己调整**（展开三组 FilterChip，预填推荐值，点「应用」写所选值，可「返回推荐」）；
- 下滑、点遮罩或按返回键等于取消：等级和设置都不写；等级已存在时保留原等级；
- 等级推荐：A1–B2 中文界面，C1–C2 English；词义 A1–A2 中文、B1–B2 中英对照、C1–C2 英文；
  导读 A1–B1 双语带读、B2–C1 英文带读、C2 沉浸。C1 保留英文带读而不是沉浸，是因为文学
  原著仍需要背景铺垫。

### 书籍页与详细信息（2026-11-21）

书城的书卡是整卡可点的：内置书卡、自定义源目录卡与「已下载」列表行都进**书籍页**，只有卡片上
自带的「立即阅读 / 下载」按钮保持原行为。版式参考阅读类商店的书籍页：

- 头部：默认排版封面、书名（中文界面显示中文书名、英文界面显示英文书名）、作者，以及一行
  「制作者：Pagelence」；
- 封面下是**四格数据条**，用细分隔线分开：等级（`A2` 大字 + 「难度」小字）、分类（图标 +
  「文学作品」）、词汇量（`2.5` 大字 + 「万词」小字，按万四舍五入到一位小数）、来源（图标 +
  「内置 / 本地导入 / 自定义源名」）；
- 按钮两枚：「加入书架 / 已在书架」与「立即阅读」。未下载的自定义源书目为「下载 / 更新」，
  制作中的书两枚置灰；加入书架写 `preferences.shelfBookIds`，不改进度，书架里以 0% 出现，再点
  一次即移除；
- 「关于此书 →」进入详细信息页；往下依次是内容简介、标签（描边胶囊）与章节目录（点章从该章
  第一个单元开始读）。没有评分与评价。

**详细信息页**参考同一套版式：顶栏是小封面 + 书名 + 「详细信息」，正文先是书籍简介，再是
「图书信息」：作者、单词量（`2.5 万词`）、等级、分类、制作者、出版信息（出版商 · 版本）、
授权信息（原书授权与制作授权，含公有领域地区与说明）、语言、章节数、单元数、来源。没有
「符合加入家人共享内容库」一栏。

数据来自 `content/books-index.json`（等级、词数、制作者、分类、标签、`licenses`）、
`book.json`（章节、简介、出版信息）、`store.json`（未制作书目的身份与标签）与源目录
（未下载书目的身份、简介、体积、来源与制作者）。

## 六·六、书城与书源

- 页面首屏是**内置书架**：`content/store.json` 列出五档计划书目（A2 杜立德、B1 爱丽丝、
  B2 四签名、C1 盖茨比、C2 红字），顶部用 FilterChip 按 CEFR 筛选。
- 是否可读以内容清单为准：随包的两本显示「内置 / 立即阅读」，其余显示「制作中」和一句说明，
  不给下载按钮，也不假装可读。
- 默认源 `DefaultBookSource.AVAILABLE = false`：界面不出现默认源卡片，打开书城也不请求它；
  托管上线后改回 `true` 即可复用 AUTO/DIRECT/MIRROR 与 ETag 缓存。自定义源列表仍保留在页面底部。
- 右上角溢出菜单收纳三个入口：**导入本地书籍包**、**导入线上书籍包**、**添加源**。前两项只装
  一本书，不保存书源；「添加源」打开原有的自定义源对话框，页面底部不再重复放添加按钮。
- 本地导入用系统文件选择器选 `.pagelence`，应用自己读内容、不需要存储权限；线上导入填包的直链
  （HTTPS，或已打开局域网 HTTP 的本机地址）。两条路径共用 `SourceManager.importPackage`：
  `BookPackageReader` + `ContentValidator` 校验通过才原子安装；导入中顶栏显示进度，成功后提示
  「已导入《书名》」并在「已下载」里标「本地导入」或「线上导入」。
- 导入与随包内置书同 `bookId` 的包会被拒绝，避免遮蔽内置书及其进度；同一 `bookId` 的重复导入
  按更新处理，阅读进度保留。
- 一本书可来自多个源：卡片显示来源数，下载前弹出「选择下载来源」；安装摘要与目录一致时
  视为同一本，不重复下载。
- 下载中按钮变为进度指示；成功后提示「已下载，书架里可直接读」，失败按类型给出原因。
- 自定义源默认启用、可停用与删除；同一 bookId 冲突由用户选择。
- 网络只在点按「刷新自定义源」/下载时发生；`AndroidHttpFetcher` 限制超时、重定向与体积，
  `network_security_config` 默认禁明文。
- 下载目录 `filesDir/downloaded/` 是 `FileContentRepository` 的第二内容根；安装/移除后
  调用 `AppGraph.refreshContent()` 重新读取清单。

## 六·九、读完页与重读（2026-11-22，T139）

读完一本书不再直接掉回书架，而是进入独立的结束页；书也不会从书架消失。

- **完成标记**：`BookProgress.finishedAt`（ISO-8601 UTC，v2 可选字段）。离开最后一个单元的
  语法页、或点「继续下一段 / 读完全书」时写入；重读、同步不改写已有时间；手工删掉一个已读
  单元后，加载时由 `ProgressSemantics.restore` 置空，书回到「在读」。
- **三条进入路径**：最后一单元点「读完全书」；测验交卷后自动前进到该单元语法（无语法时直接
  完成）；最后一单元语法页按返回。判断用 `ProgressSemantics.justFinished`（写入前为空、写入
  后非空），重读时不会重复弹。
- **读完页**（`Screen.BOOK_FINISHED` + `FinishedBookUi`）：书名、封面、读完日期，以及单元数、
  原文词数、本书收词数三项数字；操作「再读一遍」「返回书架」「去书城看看」。从书籍页的
  「读完总结」也能再次进入。
- **重读**：只把续读点移回第一单元开头，不清 `readUnitIds`、不改 `finishedAt`；书架仍在
  「已读完」，「我的」的读完本数与已读单元不变。
- **书架**：`LibraryRules.sections` 返回「在读 / 已读完」两组；在读按 `lastReadAt` 倒序，
  已读完按 `finishedAt` 倒序（缺时间的旧记录回退到 `lastReadAt`）。点已读完卡片进书籍页，
  卡片上的「再读一遍」直接开书。
- 文案新增 12 条，`tools/check_strings.py` 中英成对。

## 七、模块边界

```
app-phone (Android application, applicationId com.pagelence)
  MainActivity、AppGraph（手工装配）、PagelenceViewModel（状态/导航/TTS 编排）、AssetManagerReader
    ├── ui-m3 (Android library, Compose Material 3)
    │     页面、组件、主题、UI 模型、双语文案；只接数据与回调
    ├── presentation (纯 JVM)
    │    UI 模型、双语 Strings、ReaderSession（续读点/读完判定）、
    │    ReaderFlow（页序）、LibraryPresenter（书架/我的）、ReaderPresenter（单元状态）
    ├── data (纯 JVM)
    │     state.json 读写；进度、卡片、偏好、等级与日活仓库
    └── core (纯 JVM)
          内容模型与解析、句子切分、校验、进度规则、查词顺序、卡片、偏好、
          等级默认值、日活规则、测验评分、词条状态机、段落分页
```

- `ui-m3` 不依赖 `data`，不写存储规则；分页高度测量在 UI，分组规则在 `:core`。
- `PagelenceViewModel` 把 `:core` 结果映射成 UI 模型；导航栈、四栏、TTS 结果映射也在壳层。
- `SpeechController` 在 `app-phone`，用系统 TTS；`ui-m3` 只接 `onSpeakWord/onSpeakSentence`。
- 随包内容经 `ContentSource` 读取：APK 用 `AssetContentSource`（`AssetManager` 适配），下载书用 `FileContentSource`；不再复制到 `filesDir`。
- 书架、我的、书城只读 `books-index.json` 与每本书的 `outline.json`；`book.json` 在打开书时才解析。

## 八、存储

用户数据只有一份 `state.json`（`filesDir/state.json`），格式即 `docs/progress-format.md` 的 `ReadingState`
v2：进度、已读单元、生词卡（含墓碑）、偏好（主题/字号/`speechRate`/`seenGuideUnits`/
`levelOnboardingDone`）、等级、日活、`deviceId`、`updatedAt`。写入用临时文件 + 原子改名；
成功读取后保留一份 `state.json.bak`，主文件损坏时从备份恢复并把坏文件存为
`state.json.corrupt`，只有主备都坏才回退为空状态并在启动时提示。v1 升级时自动迁移，
更高版本只读已知字段、不自动改写。

阅读页的续读点在翻页、切换环节、滚动停止和答题时写入：连续变化按 300ms 防抖合并，
写入串行化，旧快照不会覆盖新位置；`ON_STOP` 与 `onCleared` 强制 flush。进程被杀后从
同一页、同一环节和同一组测验选项恢复，段落锚点与续读点在同一次写入里更新。

内容包不落在用户目录：随包内容直接从 APK `assets/` 读取，只有下载/导入的书进入
`filesDir/downloaded/`，完整词表在 `filesDir/dictionaries/`，都可用设置或书城删除。

**与设计稿的差异**：android-design.md 第九节计划 Room。M2 先实现为 `ReadingStateStore`
（纯 JVM、可单测），因为同步/导出本来就是这份 JSON；仓库接口已在 `:core` 固定。
